## Data Dictionary

| Column Name | Data Type | Description |
|------------|----------|-------------|
| `species` | string | Penguin species classification |
| `island` | string | Island where the penguin was observed |
| `bill_length_mm` | float64 | Length of the penguin’s bill (millimeters) |
| `bill_depth_mm` | float64 | Depth of the penguin’s bill (millimeters) |
| `flipper_length_mm` | float64 | Length of the penguin’s flipper (millimeters) |
| `body_mass_g` | float64 | Body mass of the penguin (grams) |
| `sex` | string | Biological sex of the penguin |
